Open the right doors.

Claviger is an open-source backend with passkeys built in. It runs as one file on your own server, keeps your data there, and lets in exactly the people who should be let in.

Who it is for

One project, two kinds of keepers.

Claviger keeps everything that makes PocketBase pleasant for developers, and adds the identity features that congregations keep asking their software for.

For developers

  • A realtime database, file storage, an admin screen and an API in one binary
  • Passkey sign-in next to password, OAuth2 and one-time codes
  • Extend it in Go or JavaScript, the same way as PocketBase
  • Logs to any OpenTelemetry collector
  • Safe rolling deploys of a single SQLite writer in containers

For congregations

  • Passkeys, so members stop forgetting passwords
  • Your members' data stays on a server you control
  • Roadmap: households, guardians and children's check-in
  • Roadmap: access that ends when safeguarding training lapses
  • Roadmap: one sign-in across a diocese or synod

How it works

Three steps to a front door.

  1. Run one file

    Download the binary for your system and start it. The database lives next to it.

    ./claviger serve
# admin screen: http://127.0.0.1:8090/_/

  2. Turn on passkeys

    In the admin screen, open your users collection and switch on passkey sign-in. Members enrol from their phone or laptop.

  3. Connect your app

    Use the PocketBase SDKs you already know. The API stays compatible.

    const pb = new PocketBase("https://keys.example.org");
await pb.collection("users").authWithPasskey();

Command and method names are shown as they will be after the rename from the PocketBase fork.

Questions

Good questions, plain answers.

How do you say “Claviger”?

KLAV-ih-jer. Church Latin speakers say KLAH-vee-jer, and that is fine too. It is Latin for “key-bearer”.

Why the keys?

A key-bearer decides who comes in. The crossed keys echo the keys of St. Peter, a sign of trust that many traditions share. They stand for what the software does: it holds the keys, and it opens the right doors.

Is it only for Catholic parishes?

No. The congregation features are for any church, synagogue, mosque or faith community, and everything else is a general-purpose backend for any app.

How does it relate to PocketBase?

Claviger is built on PocketBase by Gani Georgiev, under the MIT licence. We follow upstream releases and keep the API compatible, so the PocketBase SDKs keep working.

Where does our data live?

On the server where you run Claviger, in SQLite files you can back up and move. Nothing is sent to us.

Can older members use passkeys?

Yes. A passkey is the phone's fingerprint or face check, with nothing to remember. Reset by email link is being repaired, and recovery that the parish office can vouch for is on the roadmap.

Is it ready for production?

Passkey sign-in already runs a parish's sign-in in production. Features marked Roadmap are not built yet, and this page says so wherever they appear.

Keep the keys yourself.

Free, open source and yours to run.
